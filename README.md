
# Список задач — тестовое задание ZalogHub

Простой список задач на React + TypeScript (Vite).

## Возможности

- Добавление задачи через поле ввода и кнопку (или Enter)
- Пустую задачу или задачу из одних пробелов добавить нельзя
- Переключение задачи между выполненной и активной
- Удаление задачи
- Фильтрация: все, активные, выполненные
- Сохранение задач в localStorage — после перезагрузки страницы они остаются
- Выполненные задачи визуально отличаются (зачёркнуты, приглушённый цвет)
- Светлая и тёмная тема по системным настройкам

## Запуск

Требуется Node.js 20+.

```bash
npm install
npm run dev
```

Приложение откроется на http://localhost:5173

Сборка и просмотр production-версии:

```bash
npm run build
npm run preview
```

## Стек

- React + TypeScript
- Vite
- CSS Modules
- Без дополнительных библиотек

## Структура

```
src/
├── features/todos/
│   ├── model/          # логика: типы, редьюсер, фильтрация, хук useTodos
│   └── ui/             # компоненты: форма, фильтры, список, задача
├── shared/lib/         # переиспользуемые утилиты: localStorage, cn
├── App.tsx
└── index.css           # глобальные стили и CSS-переменные темы
```

## Решения

- Состояние задач — `useReducer` с чистым редьюсером; побочные эффекты (id, дата, localStorage) вынесены в хук `useTodos`.
- Фильтр хранится отдельно в `useState` и не сохраняется — это состояние интерфейса, а не данные.
- Данные из localStorage проверяются type guard'ом: при повреждённых данных приложение стартует с пустым списком, а не падает.
- Компоненты только отображают данные и вызывают функции из хука.
